Git & GitHub

GitHub چیست؟ آموزش GitHub برای مبتدی‌ها

GitHub چیست و چه کاربردی دارد؟ در این مقاله مفاهیم اصلی GitHub را ساده و همراه با مثال‌های کدنویسی یاد می‌گیریم.

GitHub چیست؟

GitHub یک پلتفرم آنلاین برای ذخیره، مدیریت و همکاری روی پروژه‌های برنامه‌نویسی است.

برنامه‌نویسان می‌توانند پروژه‌های خود را در GitHub قرار دهند، تغییرات پروژه را مدیریت کنند و با افراد دیگر روی یک پروژه همکاری کنند.

به زبان ساده: GitHub محلی برای نگهداری و مدیریت پروژه‌های برنامه‌نویسی است.

Git چیست؟

Git یک سیستم کنترل نسخه یا Version Control System است.

Git به ما کمک می‌کند تغییرات پروژه را ثبت کنیم و بتوانیم تاریخچه تغییرات را مشاهده کنیم.

برای مثال فرض کن یک فایل HTML داریم: 

<h1>Hello World</h1>

بعد آن را تغییر می‌دهیم: 

<h1>Welcome to CodeLearn</h1>

Git می‌تواند این تغییرات را ثبت کند تا بدانیم چه چیزی در پروژه تغییر کرده است.

تفاوت Git و GitHub

Git و GitHub یکی نیستند.

  • Git: ابزار مدیریت نسخه پروژه است.
  • GitHub: یک پلتفرم آنلاین برای میزبانی و همکاری روی پروژه‌هاست.
خلاصه: Git ابزار است؛ GitHub سرویس آنلاین است.

Repository چیست؟

Repository یا مخزن، محلی برای نگهداری فایل‌ها و تاریخچه یک پروژه در GitHub است.

برای مثال یک سایت ساده می‌تواند چنین ساختاری داشته باشد: 

my-website/
│
├── index.html
├── style.css
└── script.js

تمام این فایل‌ها می‌توانند داخل یک Repository قرار بگیرند.

Commit چیست؟

Commit را می‌توان یک نقطه ثبت‌شده از تغییرات پروژه در نظر گرفت.

در Git می‌توانیم با دستور زیر تغییرات را ثبت کنیم: 

git add .
git commit -m "Create homepage"

عبارت داخل علامت نقل‌قول، توضیح کوتاهی درباره تغییری است که انجام داده‌ایم.

Push چیست؟

اگر پروژه روی کامپیوترمان باشد و بخواهیم تغییرات را به Repository موجود در GitHub ارسال کنیم، معمولاً از Push استفاده می‌کنیم. 

git push

به شکل ساده: 

تغییرات
   ↓
Commit
   ↓
Push
   ↓
GitHub

GitHub Pages چیست؟

GitHub Pages قابلیتی است که امکان انتشار سایت‌های استاتیک از یک Repository را فراهم می‌کند.

یعنی می‌توان فایل‌های HTML، CSS و JavaScript را در Repository قرار داد و سایت را روی اینترنت منتشر کرد.

مثلاً ساختار یک سایت ساده می‌تواند این‌گونه باشد: 

website/
│
├── index.html
├── style.css
└── script.js

GitHub Pages می‌تواند این فایل‌های استاتیک را به عنوان سایت منتشر کند. 0

چرا GitHub مهم است؟

GitHub در بسیاری از پروژه‌های برنامه‌نویسی برای نگهداری کد، همکاری تیمی و مدیریت تغییرات استفاده می‌شود.

  • ذخیره پروژه‌ها
  • مدیریت نسخه‌های مختلف پروژه
  • همکاری با برنامه‌نویسان دیگر
  • مشارکت در پروژه‌های Open Source
  • ساخت Portfolio
  • انتشار سایت با GitHub Pages

جمع‌بندی

اگر بخواهیم تمام مقاله را در چند خط خلاصه کنیم: 

Git
↓
مدیریت نسخه پروژه

GitHub
↓
میزبانی و همکاری آنلاین

Repository
↓
محل نگهداری پروژه

Commit
↓
ثبت تغییرات

Push
↓
ارسال تغییرات به GitHub

اگر تازه برنامه‌نویسی را شروع کرده‌ای، لازم نیست تمام امکانات GitHub را یک‌باره یاد بگیری. ابتدا Git، Repository، Commit و Push را یاد بگیر و بعد سراغ مفاهیم پیشرفته‌تر برو.
