GitHub چیست؟

GitHub یک پلتفرم آنلاین برای ذخیره، مدیریت و به اشتراک‌گذاری پروژه‌های برنامه‌نویسی است. برنامه‌نویسان می‌توانند کدهای خود را در GitHub قرار دهند و روی پروژه‌ها همکاری کنند.

Git چیست؟

Git یک سیستم کنترل نسخه است که تغییرات پروژه را ثبت می‌کند. مثلاً اگر در یک پروژه تغییر اشتباهی ایجاد کنیم، Git کمک می‌کند به نسخه قبلی برگردیم.

Git و GitHub چه تفاوتی دارند؟

Git یک ابزار برای مدیریت نسخه پروژه است، اما GitHub یک سرویس آنلاین برای نگهداری و همکاری روی پروژه‌های Git است.

Repository چیست؟

Repository یا مخزن، محلی در GitHub برای نگهداری فایل‌ها و کدهای یک پروژه است.

مثلاً یک پروژه وب می‌تواند این ساختار را داشته باشد:

website/
├── index.html
├── style.css
└── script.js

Commit چیست؟

Commit یعنی ثبت یک مجموعه تغییرات در پروژه. برای مثال در Git می‌توانیم تغییرات را با این دستورات ثبت کنیم: 

git add .
git commit -m "Create homepage"

Push چیست؟

بعد از Commit می‌توانیم تغییرات را از کامپیوتر خود به GitHub ارسال کنیم: 

git push

جمع‌بندی

اگر تازه برنامه‌نویسی را شروع کرده‌ای، فعلاً این چهار مفهوم را یاد بگیر:

  • Git → مدیریت نسخه پروژه
  • GitHub → نگهداری آنلاین پروژه
  • Commit → ثبت تغییرات
  • Push → ارسال تغییرات به GitHub
