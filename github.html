GitHub چیست؟ آموزش ساده GitHub برای برنامه‌نویسان مبتدی اگر تازه وارد دنیای برنامه‌نویسی شده‌ای، احتمالاً اسم GitHub را زیاد شنیده‌ای. اما GitHub چیست و چرا تقریباً هر برنامه‌نویسی باید با آن آشنا باشد؟ در این مقاله GitHub را خیلی ساده و کاربردی یاد می‌گیریم. GitHub چیست؟ GitHub یک پلتفرم آنلاین برای ذخیره، مدیریت و همکاری روی پروژه‌های برنامه‌نویسی است. می‌توانی پروژه‌ات را در GitHub قرار بدهی، تغییرات آن را مدیریت کنی و در پروژه‌های دیگران نیز مشارکت داشته باشی. به زبان ساده: GitHub = جایی برای نگهداری و مدیریت پروژه‌های کدنویسی --- Git چیست؟ قبل از GitHub باید مفهوم Git را بشناسیم. Git یک سیستم کنترل نسخه (Version Control System) است که تغییرات فایل‌های پروژه را ثبت می‌کند. مثلاً فرض کن یک فایل HTML داری:

Hello World

بعد آن را تغییر می‌دهی:

Welcome to CodeLearn

Git می‌تواند تغییرات پروژه را ثبت کند تا بتوانی تاریخچه پروژه را ببینی و در صورت نیاز به نسخه قبلی برگردی. --- تفاوت Git و GitHub چیست؟ این دو را نباید با هم اشتباه بگیریم: Git| GitHub ابزار کنترل نسخه است| یک پلتفرم آنلاین است روی کامپیوتر هم اجرا می‌شود| روی اینترنت قرار دارد تغییرات پروژه را مدیریت می‌کند| پروژه‌ها را میزبانی و مدیریت می‌کند مستقل از GitHub است| از Git استفاده می‌کند پس: Git یک ابزار است؛ GitHub یک سرویس آنلاین برای کار با پروژه‌هاست. --- Repository چیست؟ یکی از مهم‌ترین اصطلاحات GitHub، Repository یا به اختصار Repo است. Repository محلی برای نگهداری فایل‌ها و تاریخچه یک پروژه است. مثلاً می‌توانی یک Repository به نام: my-website بسازی و فایل‌های سایتت را داخل آن قرار دهی: my-website/ │ ├── index.html ├── style.css └── script.js --- Commit چیست؟ وقتی تغییرات پروژه‌ات را ثبت می‌کنی، معمولاً یک Commit ایجاد می‌کنی. برای مثال در Git می‌توانی بنویسی: git add . git commit -m "Create homepage" دستور اول فایل‌های تغییرکرده را برای ثبت آماده می‌کند و دستور دوم این تغییرات را با یک پیام مشخص ثبت می‌کند. پیام Commit بهتر است توضیح کوتاهی درباره کاری باشد که انجام داده‌ای. مثلاً: Create homepage Add login page Fix navbar Update article --- Push چیست؟ بعد از اینکه تغییرات را با Git روی کامپیوتر ثبت کردی، برای فرستادن آن‌ها به Repository آنلاین می‌توانی از "git push" استفاده کنی: git push به زبان ساده: تغییرات روی کامپیوتر ↓ Commit ↓ Push ↓ GitHub --- GitHub Pages چیست؟ GitHub Pages قابلیتی برای انتشار سایت‌های استاتیک از داخل Repository است. یعنی می‌توانی فایل‌هایی مثل: HTML CSS JavaScript را در Repository قرار بدهی و سایتت را روی اینترنت منتشر کنی. مثلاً ساختار یک سایت ساده می‌تواند این باشد: website/ │ ├── index.html ├── style.css └── script.js بعد GitHub Pages می‌تواند این فایل‌ها را به عنوان یک سایت منتشر کند. --- چرا GitHub برای برنامه‌نویسان مهم است؟ GitHub فقط برای ذخیره کد نیست. از آن می‌توانی برای این کارها استفاده کنی: - نگهداری پروژه‌ها - مدیریت نسخه‌های مختلف پروژه - همکاری با برنامه‌نویسان دیگر - مشارکت در پروژه‌های Open Source - نمایش پروژه‌ها به عنوان Portfolio - انتشار سایت‌های استاتیک با GitHub Pages --- آیا یک مبتدی باید GitHub یاد بگیرد؟ بله، ولی لازم نیست از همان ابتدا همه امکانات Git و GitHub را یاد بگیری. برای شروع همین مفاهیم کافی هستند: Git Repository Commit Push Pull Branch GitHub Pages بعد از اینکه با این موارد راحت شدی، می‌توانی سراغ مفاهیم پیشرفته‌تر مثل Branching، Pull Request و Merge بروی. --- جمع‌بندی GitHub یکی از ابزارهای مهم در مسیر برنامه‌نویسی است. اگر بخواهیم خیلی خلاصه بگوییم: Git → مدیریت نسخه‌های پروژه GitHub → نگهداری و همکاری آنلاین روی پروژه‌ها Repository → محل قرارگیری پروژه Commit → ثبت تغییرات Push → ارسال تغییرات به GitHub GitHub Pages → انتشار سایت استاتیک اگر تازه برنامه‌نویسی را شروع کرده‌ای، یادگیری همین مفاهیم پایه می‌تواند شروع بسیار خوبی برای آشنایی با Git و GitHub باشد.
